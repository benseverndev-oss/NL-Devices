# Context Network Discovery

This project keeps its planning, architecture, decisions, and durable knowledge in a
**context network** under `context-network/`. That directory is the navigable "brain"
for the repo; the running prototype under `spike/` is the artifact the network is about.

> **Agents & contributors:** start at `context-network/discovery.md`. Do NOT scatter
> planning/decision notes into source directories — they belong in the network.

## Relationship to the other context sources

The network **organizes and points to** these; it does not replace or duplicate them:

- **Root design docs** (`DESIGN.md`, `BUSINESS.md`, `RESEARCH.md`, `DECISION.md`,
  `GAPS.md`, `ORCHESTRATOR.md`, `SPIKE.md`) — the authoritative thesis, architecture,
  competitive research, and the honest gap audit. The network references them.
- **`SPEC-*.md` (root) + `docs/superpowers/plans/`** — the spec→plan artifacts, one per
  closed gap. The network's architecture and decision nodes link to these.
- **User-level memory** (`~/.claude/projects/.../memory/`) — cross-session agent facts.
  Overlaps the network's status notes; the network is the committed, shared view.
